Map a Trip from a Google Sheet (Paste Link or Download Excel)

You already keep the itinerary in Google Sheets — dates down one column, ports or cities in another — because it’s easy to edit with a travel partner. What you want next is those stops on a map, without rebuilding the list pin by pin.

Two paths that work

  1. Paste a Google Sheets link shared as “Anyone with the link can view.”
  2. File → Download → Microsoft Excel (.xlsx) (or CSV), then drop the file on the map page.

For a specific tab, open that tab before you copy the link.

Sheet shape that maps cleanly

First row = headers. Required: date + place, or city / state / country. Optional: title, notes, lat/lon. Put the place in a column the importer can find — not only inside a Notes paragraph.

MemoryMap path

  1. Open https://www.memorymap.world.
  2. Paste the viewable Sheets link, or drop the downloaded Excel/CSV.
  3. Plot and review the map in your planned order.

Sample trips on the public preview (Caribbean Cruise, European Rail, L.A. to Nashville) use the same path if you want to try before your sheet is ready.

Honesty (public preview): Mapping and the souvenir file are free. Sign-in is optional. Paid credits are not for sale yet. Questions: hello@memorymap.world.

Common snags

  • Private sheet (not “anyone with the link can view”) → download Excel instead.
  • Wrong tab linked → open the itinerary tab first, then copy the URL.
  • Place names only in Notes → move them into Place/City columns.
