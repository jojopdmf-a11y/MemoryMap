Map a Trip from a Google Sheet (Paste Link or Download Excel)

You already keep the itinerary in Google Sheets — dates down one column, ports or cities in another — because it’s easy to edit with a travel partner. What you want next is those stops on a map, without rebuilding the list pin by pin.

That is the same traveler job as dropping a CSV or Excel file: keep the order you already chose (by date or preference) and turn the sheet into a clear trip map. It is not a request for a route optimizer that reshuffles addresses to shave miles off a delivery day.

Two paths that work

  1. Paste a Google Sheets link shared as “Anyone with the link can view.”
  2. File → Download → Microsoft Excel (.xlsx) (or CSV), then drop the file on the map page.

For a specific tab, open that tab before you copy the link. If the workbook has several tabs, the itinerary tab has to be the one in the URL you paste — or download Excel and drop that file instead.

Sheet shape that maps cleanly

First row = headers. Required: date + place, or city / state / country. Optional: title, notes, lat/lon. Put the place in a column the importer can find — not only inside a Notes paragraph.

That is trip-shaped data. City-style stops are enough for cruise ports, rail hubs, and road-trip overnight towns. Street-level coordinates help when you have them, but they should not be required to get a useful map. If your sheet only puts place names in a free-text Notes column and leaves Place / City blank, most importers will not know what to plot.

Apple Numbers is not a drop-in format on MemoryMap’s public preview. Export to Excel or CSV first, then drop the file — or keep the list in Google Sheets and use one of the two paths above.

What you get after plotting

After you plot, you should be able to:

  • See stops on a map in itinerary order (not a re-optimized delivery route).
  • Review the list next to the map.
  • Download a souvenir map file when the preview offers it.

That is the traveler outcome: list in, map out, keep a copy if you want one.

Common snags

  • Private sheet (not “anyone with the link can view”) → download Excel instead.
  • Wrong tab linked → open the itinerary tab first, then copy the URL.
  • Place names only in Notes → move them into Place/City columns.

When a route optimizer is the wrong tool

Use a route optimizer when the job is “hit these addresses with less driving.” Use a trip map when the job is “show the voyage I already planned.” A Google Sheet sequenced by day should stay in that order on the map.

FAQ

The paste-link path failed. What next?

If the sheet is private, download Excel (or CSV) and drop the file. The paste path needs a link shared as “Anyone with the link can view.”

It plotted the wrong tab.

Open the itinerary tab first, then copy the URL. Or download Excel and drop that file.

Will MemoryMap reorder my sheet for the shortest drive?

No. The job here is the planned order — by date or preference — not a delivery route.
