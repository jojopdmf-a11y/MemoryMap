A keepsake map starts from the places, not the filters

Family asks “where did you go?” A spreadsheet or notes app already has the answer: cities, ports, overnight towns, dates. Photos help tell the story later. They are not required to see the trip as a map.

If your only input is a camera roll, a photo-map app may fit better. If your input is a dated stop list, plot the list first. The keepsake is the map of this trip.

Common keepsake paths (and their tradeoffs)

Photo → map apps shine when every shot carries GPS. They struggle when ports and cities live in a booking email, not in EXIF.

Story / embed maps are strong for blogs and long write-ups. Setup is heavier when you only wanted a map of the stops.

Print studios can produce beautiful posters (often cruise- or route-shaped). They usually mean a paid order flow and a physical product — great when that is the goal, overkill when you want a file to keep or send yourself.

List → map → souvenir file is MemoryMap’s public-preview path: plot from CSV/Excel, a Sheets link, typed stops, or a sample, then download a souvenir map file when the preview offers it.

Tips for a good keepsake list

  • Use real place names people will recognize on a map.
  • Dates help the story read in order (embark → ports → return, or city nights in sequence).
  • Optional title/notes for favorite stops (“best dinner,” “day hike”).
  • One stop per row; header row required for spreadsheet drop.
  • Planned trips and past trips use the same plot path.
