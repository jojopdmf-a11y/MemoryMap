Trip Stops CSV Template (Date, City, State, Country)

You only need a stop list, not a 12-tab travel planner. Budget sheets, packing lists, and flight trackers are useful elsewhere. For a trip map, the file that matters is thin: one row per stop, with a date and a place (or city / state / country) so MemoryMap can plot what you already planned.

This page is the trip itinerary CSV template that matches MemoryMap’s map-ready headers — so the first drop does not produce an empty map.

Headers that MemoryMap expects

From live homepage / spreadsheet-guide language:

  • First row = headers.
  • Required: a date and a place — city or street address, or city, state, and country.
  • Optional: title, notes.
  • Optional: latitude, longitude (names can be looked up).
  • Numbers: export to Excel or CSV first. A native Numbers file is not a drop-in format on the public preview.

Canonical header row (downloadable template): 

Date,City,State,Country,Title,Notes

That is the blank file memorymap-trip-stops-template.csv in this guide’s asset set.

Single Place column also works. If you already write stops as one field (“Cozumel, Mexico”), a header such as Place (or aliases the importer recognizes like Location, Address, or Port) can stand in for city/state/country. You still want a Date column (aliases such as When, Day, or Arrival also map to date). Keep title/notes optional.

Coordinates (optional): Lat / Latitude and Lng / Lon / Longitude if you have them. Not required for overview trip pins.

Extra columns: Fine to leave in the sheet for your own planning. MemoryMap looks for the location/date-style headers above; unknown columns are ignored as long as the required ones are present and readable.

Street addresses are not required for overview trip pins. City- or port-style names are enough for cruises, rail hubs, and road-trip overnights.

Google Sheets

  1. Open a new Sheet and paste the header row (or import the CSV).
  2. Add one stop per row.
  3. Either File → Download → Comma Separated Values (.csv) or Excel, then drop the file on MemoryMap — or share as “Anyone with the link can view” and paste the link (open the right tab before copying). See Map a trip from a Google Sheet.

Excel / Numbers

  • Excel: save or export CSV, or drop .xlsx on the homepage.
  • Numbers: export to Excel or CSV first, then drop. Do not upload the native Numbers file.

Mistakes that create empty maps

  • No header row — first row must be titles, not a stop.
  • Place only in Notes — put the place in Place or City / State / Country.
  • Native Numbers upload — export CSV/Excel first.
  • Ambiguous city names without country — add country (or state) when names collide.
  • Wrong Sheets tab — open the tab you want before copying the link.
  • Empty file or headers with no data rows — add at least one stop under the headers.

FAQ

What are the exact required headers?

A header row, plus a date and a place — or city / state / country. Title and notes optional; lat/lng optional.

City/state/country vs a single Place column?

Either works. The canonical downloadable template uses Date,City,State,Country,Title,Notes. A Place column is fine when that matches how you already write stops.

Do I need street addresses?

No for overview trip pins. City- or port-style names are enough. Addresses or coordinates help when you have them.

Can I add extra columns?

Yes for your own notes. Keep the required date/location headers; MemoryMap ignores columns it does not use for plotting.

Numbers or Sheets?

Numbers → export Excel/CSV before drop. Sheets → download CSV/Excel or paste a viewable link.
